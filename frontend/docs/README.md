## 当前页面结构

主页面由以下模块组成：

- `PoolPanel.vue`：干员池与筛选区
- `SavedTeamsPanel.vue`：已保存编队与合集区
- `TeamPanel.vue`：当前编队与盟约效果区
- `SaveTeamModal.vue`：保存/编辑编队弹窗
- `ShareModal.vue`：分享码弹窗
- `ImportModal.vue`：导入分享码弹窗

## 当前状态划分

多个组件之间共享的核心状态主要包括：

- 当前编队数据
- 已保存编队
- 编队合集
- 分享码预览数据
- 弹窗开关状态
- 临时提示消息

这些逻辑目前主要通过 `src/composables` 下的组合式函数管理。

# 安全策略

本项目是纯前端静态站点：没有后端、没有账号、不收集任何用户数据，所有编队与偏好只存在浏览器 `localStorage`。因此攻击面集中在**解析不可信输入**（分享码、粘贴内容）与**依赖链**上。

## 支持范围

只为 `master` 分支的最新代码提供修复。项目通过 GitHub Pages 持续部署，没有历史版本维护分支。

| 版本 | 是否支持 |
| --- | --- |
| `master`（线上版本） | ✅ |
| 其它分支 / fork | ❌ |

## 报告安全问题

**请不要在公开 issue 里描述漏洞细节。**

优先使用 GitHub 的私密报告入口：

<https://github.com/yeyeye613/Arknights-alliance-tool/security/advisories/new>

如果该入口不可用，请新开一个 issue，**只写「需要私下沟通安全问题」并留下联系方式**，不要在 issue 正文中写出复现步骤、受影响地址或利用代码。维护者会通过你留下的渠道继续沟通。

### 请在报告中包含

- 受影响的页面与操作路径（例如「导入分享码」）
- 复现步骤，附最小可复现输入（分享码、`localStorage` 内容）
- 影响判断：能读到什么、能改到什么、是否需要受害者主动操作
- 浏览器与版本

### 响应预期

这是个人维护的开源项目，处理时间尽力而为：

| 阶段 | 预期 |
| --- | --- |
| 确认收到 | 7 天内 |
| 初步评估与分级 | 14 天内 |

修复发布后，如你愿意，会在 `CHANGELOG.md` 中致谢（默认匿名，除非你要求在报告中署名）。

## 属于安全问题的情形

- **分享码解析导致的代码执行或数据越权**：构造的分享码在解码 / 预览阶段触发脚本执行、原型污染（`__proto__`）或读取到非预期数据
- **XSS**：通过编队名、合集名、干员名等可控文本注入脚本。当前实现全部使用 Vue 插值转义，`src/` 中没有任何 `v-html`，若发现绕过即为有效问题
- **`localStorage` 数据导致的持久化异常**：构造的存档使页面白屏、无限循环或绕过编队人数 / 装备槽上限
- **依赖链漏洞**：`vue`、`pako`、`vue-draggable-plus`、Vite / Workbox 及其传递依赖中的已知高危问题
- **Service Worker 缓存投毒**：使过期或被篡改的资源长期驻留、且无法通过正常刷新恢复
- **部署配置缺陷**：GitHub Actions 工作流中的凭据泄露、可被外部触发的越权构建
- **敏感信息泄露**：仓库中误提交令牌、密钥或他人隐私数据

## 不属于安全问题

以下情况请按普通 issue 或 PR 处理：

- 游戏数据错误、盟约效果文案与实际不符（请附 PRTS 依据）
- 界面错位、移动端滚动异常、拖拽手感问题
- 分享码过长、导入后干员丢失等兼容性问题
- 依赖的**低危 / 无利用路径**告警，或需要用户先手动修改 `localStorage` 才能触发的自伤场景
- 需要设备已被物理控制、浏览器已被装插件的前提
- 游戏素材与数据的版权归属问题（见 [README](../README.md#致谢)）

## 已有安全设计

供评估时参考，这些是有意为之而非疏漏：

- **不发起业务网络请求**：除同源静态资源外无外连，不存在 CSRF / SSRF 面
- **无第三方统计与埋点**：不加载任何分析脚本，不写 cookie
- **分享码是数据不是代码**：v3 为纯二进制解析，v1/v2 走 `JSON.parse`，不做 `eval` / `new Function`
- **图片地址由名字拼装**：`resource/image/头像_<name>.png`，不走用户提供的 URL，无法指向外部域
- **存档读取全部包 try/catch**：单个键解析失败只回退该键，避免脏数据导致整页不可用
- **PWA 更新需用户确认**：`prompt` 模式，不会在用户编辑时静默替换资源

## 贡献者的安全责任

- 不提交任何真实令牌、密钥、个人路径；本地配置写进 `.env.local`（已在 `.gitignore`）
- 引入新依赖前确认其维护状态与体积，优先复用现有依赖
- 涉及解析外部输入（分享码、粘贴内容、存档）的改动，必须为异常路径补测试
- 不在代码或注释中写入内部地址、他人账号等信息

## 披露政策

在修复发布前不公开细节。修复发布后，经报告者同意可公开技术细节；本项目不设有偿漏洞赏金。
